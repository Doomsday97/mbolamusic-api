# MbôláMusic

La API y plataforma de streaming de música para Guinea Ecuatorial. Permite a los oyentes escuchar y descargar música offline, y a los artistas locales subir sus canciones y monetizarlas.


# Hola Soy Doomday97!
Desarrollador full stack apasionado por crear tecnología con impacto real en Guinea Ecuatorial. MbôláMusic nació para dar a los artistas locales una plataforma propia de streaming y monetización, adaptada a la realidad del país.## 🚀 Sobre MbôláMusic

MbôláMusic es una app de streaming y descarga de música pensada para Guinea Ecuatorial, con soporte multi-idioma (español, francés, portugués e inglés).

**Funcionalidades principales:**
- 🎧 Streaming en alta calidad
- 📥 Descarga offline con cifrado AES-128
- 🔥 Charts y tendencias de canciones
- 💳 Pago flexible: por reproducción (50 FCFA) o suscripción mensual (2.000 FCFA)
- 🎤 Perfiles de artista con subida de música y reparto de ingresos (70% para el artista)
- 🌍 Multi-idioma
- 🛠️ Panel de administración completo (usuarios, pagos, estadísticas, artistas, canciones, suscripciones)

Disponible actualmente como APK para Android, con iOS próximamente.
## 📎 Apéndice

- Backend: API REST construida en Node.js con Prisma como ORM
- Contenedores: Docker y docker-compose incluidos para desarrollo local
- Despliegue: configurado para Render (render.yaml) y Heroku (Procfile)
- Tests: suite de pruebas con Jest
- Panel admin disponible en `/admin`
- APK de Android disponible en `/mbolamusic.apk`

## 🛠️ Stack tecnológico

- **Backend:** Node.js + Express
- **Base de datos / ORM:** Prisma
- **Contenedores:** Docker, docker-compose
- **Testing:** Jest
- **Despliegue:** Render / Heroku
- **Frontend web:** HTML, JavaScript
- **App móvil:** Android (APK nativo)
